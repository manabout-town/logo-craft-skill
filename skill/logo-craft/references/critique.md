# 로고 비평 프레임

시안을 볼 때마다 이 문서대로 실행한다. 형식을 바꾸지 않는다.

## 1. 비평의 원칙

1. 지적이 본문이다. 칭찬은 맨 마지막 한 줄로만 쓴다. 서두에 칭찬을 깔지 않는다.
2. 모든 지적에는 검증 가능한 근거를 붙인다. 근거는 배율·픽셀·개수·비율·색상값 중 하나로 말한다.
   - 금지: "촌스럽다", "임팩트가 약하다", "좀 더 세련되면 좋겠다", "느낌이 안 산다"
   - 통과: "16px에서 잎맥 3줄이 한 덩어리로 뭉친다", "심볼 획 3.2px vs 워드마크 스템 1.8px로 1.8배 차이난다"
3. 고치는 법을 함께 준다. 문제만 던지면 비평이 아니라 감상이다. 수치나 동작으로 지시한다.
4. 시안이 3개 이상이면 반드시 순위를 매기고 이유를 댄다. "다 좋다", "취향 차이다"는 답이 아니다.
5. 모르는 건 모른다고 한다. 이미지가 저해상도라 획 굵기를 못 재면 "측정 불가, 벡터 원본 요청"이라고 쓴다. 추측으로 근거를 지어내지 않는다.
6. 지적은 최대 5개까지만 쓴다. 그 이상은 초보가 소화하지 못한다. 심각한 순으로 자른다.

## 2. 고정 출력 템플릿

시안을 볼 때는 항상 아래 형식 그대로 출력한다. 섹션 이름·순서·개수를 바꾸지 않는다.

```
## 판정
{통과 | 조건부 | 재작업} — {한 문장 근거}

## 합격기준
| # | 기준 | 판정 | 근거 |
|---|------|------|------|
| 1 | 16px 식별 | 통과/미달 | 미달이면 무엇이 뭉치는지 |
| 2 | 흑백 1색 성립 | 통과/미달 | 미달이면 어디가 무너지는지 |
| 3 | 반전 성립 | 통과/미달 | 미달이면 어느 형태가 사라지는지 |
| 4 | 경쟁사 3곳과 실루엣 차별 | 통과/미달 | 비교한 3곳 이름 + 겹치는 지점 |
| 5 | 형태의 이유 한 문장 | 통과/미달 | 설명 문장 또는 설명 불가 사유 |
| 6 | 버린 시안 30개 이상 | 통과/미달 | 확인된 개수 |

## 형태 지적
1. [치명] {문제} — {근거}
2. [중대] {문제} — {근거}
3. [경미] {문제} — {근거}
(최대 5개, 심각한 순. 심각도는 치명/중대/경미 셋 중 하나)

## 고치는 법
1. {위 1번에 대한 조치} — {수치 또는 동작}
2. {위 2번에 대한 조치} — {수치 또는 동작}
(지적 번호와 1:1 대응. 개수가 다르면 형식 위반)

## 다음에 할 것
{딱 하나. 다음 판을 뜨기 위해 지금 당장 할 행동 한 가지}

## 살릴 것
{한 줄. 다음 판에서도 버리지 말아야 할 요소}
```

시안이 3개 이상이면 위 템플릿 **맨 앞에** 아래 블록을 붙인다. 그다음 1위 시안에 대해서만 위 템플릿을 채운다.

```
## 순위
1위 {이름} — {한 문장 이유}
2위 {이름} — {한 문장 이유}
3위 {이름} — {한 문장 이유}
탈락 {이름} — {버리는 이유}
```

판정 기준:
- **통과** = 합격기준 6개 전부 통과, 치명 지적 0개
- **조건부** = 합격기준 1개 이하 미달, 치명 지적 0개
- **재작업** = 합격기준 2개 이상 미달이거나 치명 지적 1개 이상

## 3. 합격기준 6개 판정 절차

각 기준은 아래 절차로만 판정한다. 인상으로 판정하지 않는다.

### ① 16px 식별
- 시안을 16px 높이로 축소해 실제로 렌더한다. 축소본을 보지 않고 판정하지 않는다.
- 통과 조건: 형태의 정체를 알아볼 수 있고, 붙어서 뭉친 획이 없다.
- 미달 근거는 "무엇이 무엇과 붙었는지"로 쓴다. 예: "심볼 하단 두 획이 붙어 U가 O로 보인다."

### ② 흑백 1색 성립
- 전체를 100% 검정 한 색으로 채운다(그레이스케일이 아니라 1색이다).
- 통과 조건: 색 없이도 형태가 구분되고, 의도한 실루엣이 남는다.
- 미달 근거: "색으로만 나뉘던 A면과 B면이 한 덩어리가 된다."

### ③ 반전 성립
- 검정 배경에 흰 로고로 렌더한다.
- 통과 조건: 정방향과 같은 형태로 읽히고, 얇은 획이 날아가지 않는다.
- 미달 근거: "반전 시 획이 팽창해 속공간 2px가 0.5px로 줄어 막힌다."

### ④ 경쟁사 3곳과 실루엣 차별
- 같은 카테고리 실제 브랜드 3곳을 지목한다. 이름을 반드시 적는다. "일반적인 카페 로고들"은 지목이 아니다.
- 4개(경쟁사 3 + 시안)를 같은 높이 1색 실루엣으로 나란히 놓는다.
- 통과 조건: 실루엣만으로 시안을 골라낼 수 있다.
- 미달 근거: "B사와 둘 다 원형 테두리 + 중앙 세리프 이니셜로 실루엣이 겹친다."

### ⑤ 형태의 이유를 한 문장으로
- 형태를 왜 그렇게 했는지 한 문장으로 쓴다. 두 문장이 되면 미달이다.
- 통과 조건: 문장에 이 브랜드 고유의 사실이 들어 있다.
- 미달 예: "신뢰와 성장을 상징합니다." (어느 브랜드에나 붙는 문장이면 미달)
- 통과 예: "밑변만 잘린 사각형은 매장 입구의 처마 형태를 그대로 딴 것이다."

### ⑥ 버린 시안 30개 이상
- 스케치·시안 파일 개수를 실제로 센다. 확인이 안 되면 "확인 불가"로 쓰고 미달 처리한다.
- 통과 조건: 30개 이상을 버렸고, 버린 것 중 왜 버렸는지 말할 수 있는 게 3개 이상 있다.
- 변형(색만 다른 것, 자간만 다른 것)은 세지 않는다. 형태가 다른 것만 센다.

## 4. 관찰 체크리스트

각 항목은 "무엇을 보고 → 무엇으로 판정하는지"다. 눈으로 확인한 것만 쓴다.

### 형태
| 볼 것 | 판정 방법 |
|-------|-----------|
| 실루엣 | 전체를 100% 검정 한 덩어리로 채워 본다. 여기서 정체를 못 알아보면 형태가 아니라 디테일에 기대고 있는 것 |
| 요소 개수 | 독립된 형태 조각을 센다. 3개 이상이면 하나로 합치거나 버릴 후보 |
| 시각적 무게중심 | 눈을 가늘게 뜨고 어디가 제일 어두운지 본다. 의도한 초점과 다르면 미달 |
| 네거티브 스페이스 | 형태 사이 빈 공간이 우연인지 설계인지 본다. 빈 공간이 의미 없는 자투리면 형태를 다시 짠다 |
| 축소 붕괴점 | 128 → 64 → 32 → 16px 순으로 줄이며 처음 무너지는 배율을 기록한다 |

### 선·굵기
| 볼 것 | 판정 방법 |
|-------|-----------|
| 획 굵기 일관성 | 획 굵기를 3군데 이상 재서 값을 비교한다. 의도적 대비가 아닌데 차이가 나면 미달 |
| 심볼 vs 글자 굵기 | 심볼 획 두께 대 워드마크 스템 두께 비율. 1:1에 가까워야 한 덩어리로 보인다. 1.3배 넘으면 지적 |
| 속공간 막힘 | 16px에서 획 사이 틈이 몇 px인지 본다. 1px 미만이면 붙어서 뭉친다 |
| 획 끝처리 | 라운드/직각/기울임이 섞여 있는지 본다. 이유 없이 섞이면 미달 |

### 곡선
| 볼 것 | 판정 방법 |
|-------|-----------|
| 앵커 포인트 개수 | 원 하나에 앵커 4개가 기본. 그 이상이면 이유가 있어야 한다. 곡선 하나에 6개 넘으면 지적 |
| 앵커 위치 | 극점(12·3·6·9시)에 앵커가 있는지. 극점을 벗어나면 곡선이 흔들린다 |
| 곡률 연속성 | 곡선을 크게 키워 외곽선만 보고 울퉁불퉁한 구간을 찾는다. 직선→곡선 접합부가 꺾이면 미달 |
| 원의 왜곡 | 정원이어야 할 곳이 타원인지 잰다. 가로/세로 반경 차이가 있으면 수치로 쓴다 |

### 정렬
| 볼 것 | 판정 방법 |
|-------|-----------|
| 광학적 정렬 vs 수치적 정렬 | 아래 설명 참조. 좌표값이 맞아도 눈에 틀려 보이면 좌표가 틀린 것이다 |
| 베이스라인 | 심볼 하단과 글자 베이스라인이 같은 선인지 |
| 그리드 이탈 | 형태가 기준 그리드 위에 놓였는지, 소수점 좌표로 흐려졌는지 |

**광학적 정렬이란:** 사람 눈은 면적과 형태로 위치를 판단하지, 바운딩 박스로 판단하지 않는다. 원과 사각형을 같은 높이로 놓으면 원이 작아 보이고, 삼각형을 박스 중앙에 놓으면 왼쪽으로 쏠려 보인다. 수치를 맞추면 틀려 보이고, 눈에 맞추면 수치가 틀어진다. **눈이 맞다.** 좌표가 딱 떨어진다는 이유로 어색한 정렬을 방어하지 않는다. 판정법: 시안을 좌우 반전해서 본다. 반전했을 때 쏠림이 반대로 느껴지면 광학 보정이 안 된 것이다.

### 타이포
| 볼 것 | 판정 방법 |
|-------|-----------|
| 자간 | 글자 사이 "면적"이 균일한지 본다. 간격이 아니라 면적이다. AV는 붙고 IN은 벌어진다 |
| 굵기 대비 | 워드마크 굵기가 심볼과 맞는지, 크기 축소 시 먼저 사라지는지 |
| 기성 폰트 손댔는지 | 폰트를 그대로 쓴 흔적(기본 자간, 손대지 않은 글자꼴)을 찾는다. 그대로면 로고가 아니라 타이핑이다 |
| 한글 받침 | 받침 있는 글자와 없는 글자의 세로 무게 차이, 받침 획이 축소 시 붙는지 |
| 한글 중성/종성 간격 | 자소 사이 틈이 16px에서 살아있는지 |

### 조합(lock-up)
| 볼 것 | 판정 방법 |
|-------|-----------|
| 크기 비율 | 심볼 높이 대 대문자 높이(또는 한글 글자높이) 비율을 잰다. 값이 정해져 있어야 한다 |
| 정렬 기준선 | 심볼이 글자의 무엇에 맞았는지(x-height 중앙/캡 중앙/광학 중앙) 하나로 답할 수 있어야 한다 |
| 여백 규칙 | 심볼과 글자 사이 간격이 어떤 단위의 배수인지. "보기 좋게"는 규칙이 아니다 |
| 배리에이션 | 가로형/세로형/심볼 단독 3종이 같은 규칙에서 나왔는지 |

### 색
| 볼 것 | 판정 방법 |
|-------|-----------|
| 명도 대비 | 배경과의 대비를 잰다. 로고 텍스트는 4.5:1 이상, 심볼 형태는 3:1 이상 |
| 1색 변환 | 그레이스케일로 바꿨을 때 색으로만 구분되던 면이 붙는지 |
| 배경 위 대비 | 흰 배경·검정 배경·중간 회색(#808080)·브랜드 컬러 배경 4종에 얹어 본다 |
| 색 개수 | 3색 넘으면 지적. 인쇄·자수·각인에서 비용과 재현성이 무너진다 |

## 5. 흔한 초보 실수 사전

| # | 증상 | 원인 | 고치는 법 |
|---|------|------|-----------|
| 1 | 16px에서 심볼이 검은 덩어리가 됨 | 획이 굵어 속공간이 막힘 | 획을 10~20% 얇게, 속공간을 획 굵기 이상으로 벌린다 |
| 2 | 곡선 외곽이 울퉁불퉁 | 앵커 포인트 과다, 극점 이탈 | 앵커를 극점 4개로 재작도. 자동 추적(이미지 트레이스) 결과를 그대로 쓰지 않는다 |
| 3 | 심볼과 글자가 따로 논다 | 획 굵기 불일치 | 심볼 획을 워드마크 스템 굵기의 1.0~1.2배로 맞춘다 |
| 4 | 좌우 대칭인데 지루함 | 대칭 강박 | 한 축만 비대칭으로 깬다. 대칭은 안전하지만 기억에 안 남는다 |
| 5 | 로고가 아니라 그냥 글자로 보임 | 기성 폰트 그대로 사용 | 최소 한 글자 이상 자소를 손보고 자간을 전부 수동 조정한다 |
| 6 | 무슨 회사인지 알겠는데 안 외워짐 | 요소 3개 이상(집+나무+태양) | 하나로 줄인다. 셋을 다 넣으면 아무것도 안 남는다 |
| 7 | 앱 아이콘으로 쓰면 죽음 | 그라데이션 의존 | 1색 흑백으로 성립시킨 뒤 색을 얹는다. 순서를 뒤집지 않는다 |
| 8 | 문서마다 로고 크기가 제각각 | 여백(clear space) 규칙 없음 | 심볼 폭의 1/2 같은 자기참조 단위로 최소 여백을 정의한다 |
| 9 | 반전(흰 로고)하면 뚱뚱해 보임 | 광학 팽창 미보정 | 반전 전용 버전의 획을 2~5% 얇게 만든다 |
| 10 | 원 안의 삼각형이 왼쪽으로 쏠려 보임 | 바운딩 박스 중앙정렬 | 폭의 5~10%만큼 오른쪽으로 민다 |
| 11 | 글자 사이가 들쭉날쭉 | 간격을 수치로 맞춤 | 면적 기준으로 재조정. 뒤집어 보거나 흐리게 해서 확인한다 |
| 12 | 축소하면 얇은 선이 사라짐 | 최소 획 굵기 미확보 | 최소 사용 크기에서 획이 최소 1px(인쇄 0.25pt) 이상이 되게 굵기를 올린다 |
| 13 | 실루엣이 경쟁사와 똑같음 | 카테고리 클리셰(말풍선·지구본·잎사귀) | 경쟁사 3곳 실루엣을 나란히 놓고 겹치면 버린다 |
| 14 | 자수·각인 견적이 안 나옴 | 디테일 과다, 색 4개 이상 | 색 2~3개로 줄이고 1mm 이하 디테일을 제거한다 |
| 15 | 정사각 아이콘에 넣으면 답답함 | 심볼이 프레임에 꽉 참 | 안전영역을 프레임의 80% 이내로 잡고 시각 면적 기준으로 다시 앉힌다 |
| 16 | 인쇄물에서 색이 다르게 나옴 | RGB 전용 색 선정 | CMYK/별색 변환 결과를 먼저 보고 색을 정한다 |
| 17 | 형태를 왜 그렇게 했냐고 물으면 말이 길어짐 | 컨셉이 사후 정당화 | 한 문장으로 못 말하면 형태를 바꾼다. 설명을 늘리지 않는다 |

| 19 | 화면에선 좋은데 명함에선 별로임 | 화면에서만 검증 | 실물 크기로 출력해서 팔 길이만큼 떨어져 본다 |

## 6. 광학적 보정 목록

아래 값은 실무 통용 시작점이다. **정확한 값은 눈으로 확인해야 한다.** 수치를 적용한 뒤 반드시 실제 크기로 보고 최종 결정한다.

| 상황 | 눈에 보이는 현상 | 보정 방향 | 통용 범위 |
|------|-----------------|-----------|-----------|
| 원 vs 사각형 같은 높이 | 원이 작아 보임 | 원을 키운다 | 2~5% |
| 삼각형 vs 사각형 같은 높이 | 삼각형이 작아 보임 | 삼각형을 키운다 | 5~10% |
| 원형 글자(O·C·S)와 평평한 글자(H·I) | 원형이 작아 보임 | 위아래로 오버슛 | 각 0.5~2% |
| 뾰족한 글자(A·V·W) 꼭짓점 | 잘려 보임 | 오버슛 | 1~2% |
| 삼각형 좌우 중앙정렬(재생 버튼) | 왼쪽으로 쏠려 보임 | 오른쪽으로 이동 | 폭의 5~10% |
| 삼각형 상하 중앙정렬 | 아래가 무거워 보임 | 위로 이동 | 높이의 2~5% |
| 가로획과 세로획 같은 굵기 | 가로획이 더 굵어 보임 | 가로획을 얇게 | 5~15% |
| 십자·플러스 형태 | 가로바가 두꺼워 보임 | 가로바를 얇게 | 5~10% |
| 텍스트 박스 수직 중앙 | 아래로 처져 보임 | 위로 올린다 | 박스 높이의 2~4% |
| 흑백 반전(검정 바탕 흰 형태) | 흰 형태가 팽창해 보임 | 획을 얇게 | 2~5% |
| 곡선 글자 사이드베어링 | 곡선 쪽이 벌어져 보임 | 사이드베어링 축소 | 직선 대비 60~80% |
| 원형 심볼의 여백 | 사각 심볼보다 떠 보임 | 여백 축소 | 10~20% |
| 아이콘 세트 크기 통일 | 높이 맞추면 제각각 | 높이가 아닌 시각 면적 기준으로 정규화 | — |

검증 절차: 보정 후 시안을 (1) 좌우 반전, (2) 상하 반전, (3) 가우시안 블러 4px 적용 세 가지로 본다. 세 경우 모두 쏠림이 느껴지지 않으면 보정 완료다.

## 7. 비평을 받는 쪽 규칙

1. **변명하지 않는다.** 설명을 붙여야 이해되는 로고는 설명을 못 하는 로고다. "이게 사실은 A와 B의 결합인데요"는 지적에 대한 답이 아니다.
2. **반복되는 지적을 기록한다.** 프로젝트 루트의 `CRITIQUE.md`에 날짜·지적·조치를 남긴다. 같은 지적이 3회 이상 나오면 그게 진짜 약점이다. 취향이 아니라 습관이다.
3. **5개 중 3개만 고쳐도 다음 판으로 간다.** 완벽해질 때까지 붙잡지 않는다. 판을 많이 도는 쪽이 이긴다.
4. **못 고친 2개는 버리지 말고 적어둔다.** 다음 판에서 자동으로 재검토 대상이 된다.
5. **근거 없는 칭찬을 요구하지 않는다.** "괜찮나요?"가 아니라 "16px에서 뭉치나요?"로 묻는다.
